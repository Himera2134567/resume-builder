# Resume Builder

Локальное веб-приложение для создания резюме на Django. Собирает профиль, навыки, проекты, опыт, образование и достижения в единую страницу и PDF с поддержкой кириллицы. Исходная папка проекта: `summarizee`.

## Что умеет

- Редактирование независимых разделов и прикрепление файлов и фото.
- Хранение в SQLite; отдельное резюме для каждой браузерной сессии.
- Просмотр по UUID-ссылке после нажатия «Опубликовать», снятие с публикации.
- PDF через ReportLab и шрифт DejaVu Sans. Черновой PDF доступен владельцу сессии; публичный — после публикации.
- Фото и вложения черновиков недоступны другой сессии.
- Помощь с описанием навыков: локальный шаблон по умолчанию; необязательный запрос OpenRouter по кнопке при явном включении интеграции.

## Windows без Python

Скачайте ZIP из [Releases](https://github.com/Himera2134567/resume-builder/releases), распакуйте целиком и запустите `ResumeBuilder.exe`. Откроется `http://127.0.0.1:8765/`. Окно консоли должно оставаться открытым; остановка — Ctrl+C. Папку `_internal` сохраняйте рядом с EXE.

```powershell
.\ResumeBuilder.exe --no-browser --port 8765
.\ResumeBuilder.exe --data-dir D:\ResumeBuilderData
```

Python, SQLite и шрифты включены. Windows x64. По умолчанию база, файлы и автоматически созданный секрет сессий хранятся в `%LOCALAPPDATA%\ResumeBuilder`, отдельно от программы. Для переноса данных остановите приложение и скопируйте **весь** каталог данных. Для возврата к редактированию требуется та же браузерная сессия; отдельной регистрации и восстановления доступа пока нет.

Ссылка с `127.0.0.1` доступна на вашем компьютере. Кнопка публикации открывает просмотр резюме в приложении и не выкладывает его в интернет. Готовая сборка слушает только localhost. Для отправки работодателю используйте PDF. Публичный хостинг, HTTPS, учётные записи, ограничения загрузок и полноценное управление доступом требуют отдельной доработки; это портфолио-прототип.

## Запуск исходников

Python 3.12:

```powershell
python -m pip install -r requirements.txt
python run.py
python run.py --self-test report.json
python -m pip install -r requirements-build.txt
python build.py
```

Миграции выполняются при запуске. `RESUME_DATA_DIR` задаёт каталог данных; `DJANGO_SECRET_KEY` — необязательный внешний ключ. `DEBUG` по умолчанию выключен. Пример переменных — `.env.example`; автоматического чтения `.env` нет, задайте переменные в среде процесса.

Для OpenRouter явно установите `OPENROUTER_ENABLED=1`, `OPENROUTER_API_KEY` и при необходимости `OPENROUTER_MODEL`. Только после этого нажатие кнопки помощи отправит перечисленные навыки внешнему сервису. Без интеграции приложение работает локально, сетевой запрос не выполняется. Онлайн-ответы сервиса в этой сборке не проверялись.

## Устройство проекта

| Часть | Назначение |
|---|---|
| `app/models.py`, `migrations/` | Резюме, проекты, достижения, опыт, образование и схема SQLite |
| `app/forms.py` | Валидация и сохранение форм |
| `app/views.py` | Обработка конструктора, просмотр, генерация описаний и PDF |
| `app/templates/`, `static/` | Интерфейс, стили, шрифты и их лицензии |
| `project/settings.py`, `urls.py` | Конфигурация, маршруты и локальная выдача файлов |
| `run.py` | Миграции и локальный WSGI-сервер Waitress |
| `app/tests.py` | Сессии, доступ к черновикам, публикация, PDF, владение записями и редиректы |
| `build.py` | Переносимая Windows-сборка |

## Проверки

Восемь автоматических тестов на изолированной SQLite и синтетическом изображении; включают кириллический PDF, защиту черновиков и отсутствие сетевого вызова без включённого AI. Проверены запуск EXE, миграции, локальные страницы и стили. Исходные база, `.env`, фото и пользовательские документы исключены из Git и релиза.

Большие тексты и вложения требуют дополнительной проверки вёрстки PDF; поля приложения не заменяют полноценную систему документов. Храните резервную копию каталога данных. Сборка не подписана цифровым сертификатом.
